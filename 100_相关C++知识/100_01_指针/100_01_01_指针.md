
# 1 创立指针 

float *  是创立一个指针 

```
float *devicePtr = null;
```

在 C++ 中的意思是：
- 声明了一个指向 **float 类型数据** 的指针，名字叫 `devicePtr`。
- 并把它初始化为 **空指针**（即目前不指向任何有效的内存地址）。


含义：
声明了一个指向 float 的指针 devicePtr。
目前它 没有指向任何有效的内存（它是空的）。
nullptr 表示 “没有地址”。

# 2 取变量的地址 &x， 取指针对应地址中的值 (解引用 derefenrence) `*devicePtr`


```
float x = 3.14f;
float *devicePtr = &x;   // devicePtr 指向变量 x 的地址

```

```
x = 3.14
       ▲
       │
devicePtr ──> &x
```



devicePtr → 保存的是 “x 的地址”
`*devicePtr `→ 就是 “x 的值”，也就是 3.14

`float *devicePtr = nullptr;` → “我有个指针，但它现在还没指向任何东西。”  
`float *devicePtr = &x;` → “我有个指针，它现在指向变量 x 的地址。”

```
std::cout << devicePtr << std::endl;   // 输出内存地址（比如 0x7ffee8...）
std::cout << *devicePtr << std::endl;  // 输出 3.14

```

|名称|内容（值）|含义|
|---|---|---|
|`x`|3.14|普通变量|
|`devicePtr`|0x7ffee8...|指向 `x` 的地址|
|`*devicePtr`|3.14|解引用 → 取出地址中的值|

|名称|含义|举例|
|---|---|---|
|`&x`|取地址符（address-of）|“告诉我 x 存在哪”|
|`*p`|解引用符（dereference）|“去 p 指的地方拿值”|
|`p`|指针本身（存储地址）|“地址保存在这里”|

# 3 calloc:  Allocate memory space on CPU

the pointer points to the addrress of first element

```
float *in_d, *in_h, *out_d, *out_h;

// Allocate on host
in_h = (float *)calloc(size, sizeof(float));
CHECK_ALLOC(in_h);


等价于 
in_h = (float *)malloc(size * sizeof(float));
memset(in_h, 0, size * sizeof(float));


使用完毕后 
free(in_h);
```


`calloc` 是 C 语言中用于 **动态内存分配** 的函数之一，它的作用是：
**`calloc` 会分配一段连续的内存，并将其全部初始化为 0。**

你的代码：
- **分配 `size` 个元素的空间**
- **每个元素的大小是 `sizeof(float)` 字节**
- **返回一段可以存放 `size` 个 `float` 的连续内存区域**
- **这段区域内的内容全部被初始化为 0**
- 最后将返回的指针转换为 `(float *)` 并赋值给 `in_h`


# 4 CUDA: cudaMalloc

```cpp
float *devicePtr = nullptr;
cudaMalloc((void **)&devicePtr, size * sizeof(float)); // 现在 devicePtr 已经指向 GPU 的内存区域了

```

```
[CPU内存]
┌───────────────────────┐
│ devicePtr (变量)      │   ← &devicePtr
│  值: 0xABCDEF00        │
└───────────────────────┘
            │
            │
            ▼
[GPU显存]
┌───────────────────────┐
│ 地址: 0xABCDEF00       │ ← devicePtr 指向这里
│ 内容: [3.14][2.71][...]│ ← *devicePtr 是第一个float值
└───────────────────────┘

```

| 步骤  | 说明                                                      |
| --- | ------------------------------------------------------- |
| 1️⃣ | 你在 CPU 端有一个变量 `float *devicePtr`                        |
| 2️⃣ | `&devicePtr` → 是指向这个变量的地址                               |
| 3️⃣ | `cudaMalloc` 在 GPU 上分配一块内存（大小 = `size * sizeof(float)`） |
| 4️⃣ | 它把那块 GPU 内存的地址写入 `devicePtr` 里                          |
| ✅   | 所以调用结束后，`devicePtr` 就指向 GPU 上的那块内存了                     |
|     |                                                         |


意思是：
1. 定义一个 GPU 上的浮点数组指针；
2. 用 `cudaMalloc` 分配 GPU 显存给它；
3. `devicePtr` 之后就指向 GPU 上的那块内存了。 `devicePtr` 是一个指向 GPU 内存的指针；
4. `*devicePtr` （dereference）是那块 GPU 内存中第一个 `float` 元素的值。

| 表达式                    | 含义                                                                           | 类型      | 举例值         |
| ---------------------- | ---------------------------------------------------------------------------- | ------- | ----------- |
| `devicePtr`            | GPU 上数据的指针（变量）.保存 GPU 内存的地址                                                  | float*  | 0xABCDEF00  |
| `&devicePtr`           | CPU 内存中保存这个指针变量的地址                                                           | float** | 0x7ffee8... |
|                        |                                                                              |         |             |
| *devicePtr             | GPU 地址中存放的第一个 float 值（例如 3.14). 在 GPU kernel 内访问：`float val = devicePtr[i];` | float   | 3.14        |
| `(void **)&devicePtr`  | 转成 `cudaMalloc` 需要的参数类型                                                      |         |             |
| `size * sizeof(float)` | 分配的字节数                                                                       |         |             |
| `cudaMalloc(...)`      | 在 GPU 上申请内存并让 `devicePtr` 指向它                                                |         |             |


1  `cudaMalloc` 是什么
`cudaMalloc` 是 CUDA 提供的一个函数，用来 **在 GPU 显存上分配内存**。
它的作用类似于普通 C 语言中的：
`malloc(size_in_bytes);`

但区别在于：
- `malloc` → 分配的是 **CPU 内存**
- `cudaMalloc` → 分配的是 **GPU（设备）内存**


2 `cudaError_t cudaMalloc(void **devPtr, size_t size);`
意思是：
- 参数 1：`void **devPtr` → 指向一个 **指针变量** 的指针（用于返回 GPU 内存地址）
- 参数 2：`size_t size` → 要分配的字节数
